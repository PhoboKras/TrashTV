## 📝 Descrição do Sistema

O **TrashTV** é uma aplicação mobile focada no universo do cinema trash. O sistema conta com:
* **Autenticação Simulada e Gestão de Usuários:** Login, cadastro e CRUD completo de usuários armazenados localmente.
* **Gerenciamento de Produtos/Filmes:** Cadastro, listagem, busca por nome, edição e exclusão de itens do catálogo.
* **Navegação Dinâmica:** Utilização combinada de `Stack Navigator` e `Bottom Tab Navigator`.
* **Apresentação da Equipe:** Tela com detalhes, funções e perfis dos desenvolvedores.
* **Fale Conosco:** Tela institucional com dados da empresa fictícia e integração direta com o WhatsApp via componente `Linking`.
* **Persistência Local:** Todos os dados de usuários e produtos são mantidos no dispositivo via `AsyncStorage`.
